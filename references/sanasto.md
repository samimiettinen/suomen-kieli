# Sanasto ja rekisteri

Lue tämä, kun teksti kuulostaa käännökseltä, sisältää englannista lainattua sanastoa tai kun sinun on päätettävä, kuuluuko sana yleiskieleen.

Perusta: Kielitoimiston sanakirja ja Kielitoimiston ohjepankki.

## 1. Turhat lainaverbit ja -sanat

Monelle englannista mukautetulle sanalle on vakiintunut suomenkielinen vastine. Ammattikielessä osa lainoista on vakiintunut, joten arvioi lukijakunta ennen korjaamista.

| Vältä | Käytä |
|---|---|
| adressoida | tarttua johonkin, käsitellä |
| implementoida | panna toimeen, toteuttaa |
| fasilitoida | ohjata, vetää, helpottaa |
| enabloida | mahdollistaa |
| eskaloida | viedä ylemmälle tasolle, kärjistyä |
| leveroida (ei rahoituksessa) | hyödyntää |
| prioritisoida | priorisoida (oikea asu), asettaa tärkeysjärjestykseen |
| onboarding | perehdytys |
| deadline | määräaika, takaraja |
| stakeholder | sidosryhmä |
| insight | havainto, oivallus |
| feedback | palaute |

Rahoituksen ja M&A:n vakiintunutta ammattisanastoa (*due diligence*, *earn-out*, *LBO*, *carve-out*) ei tarvitse suomentaa ammattilaisille kirjoitettaessa. Yleisölle kirjoitettaessa selitä termi ensimmäisellä kerralla.

## 3. Tyhjä avaus- ja lopetusretoriikka

Nämä eivät kerro lukijalle mitään. Poista ne, älä korvaa niitä toisilla fraaseilla:

- *Nykypäivän nopeasti muuttuvassa maailmassa…*
- *Tässä artikkelissa käymme läpi…*
- *On syytä huomata, että…* (kun huomattavaa ei ole)
- *Yhteenvetona voidaan todeta, että…*
- *Toivottavasti tästä oli apua!*

Myös *ei ainoastaan… vaan myös* ja *ei pelkästään… vaan* toistuvat kielimallin tekstissä selvästi useammin kuin ihmisen. Yksi käyttö tekstissä on luonteva, toistuva käyttö maneeri.

## 4. Vakiintuneet lainasanat

Kaikki lainat eivät ole anglismeja. Näitä ei pidä väkisin suomentaa: *analyysi, budjetti, brändi, data, digitalisaatio, konsultti, prosessi, projekti, resurssi, strategia, skaalautua.*

## 5. Yleiskieli ja puhekieli

Asiateksti kirjoitetaan yleiskielellä. Näitä puhekielen piirteitä kannattaa etsiä erikseen:

| Puhekieli | Yleiskieli |
|---|---|
| mä, sä | minä, sinä |
| me mennään | me menemme, menemme |
| ne menee (ihmisistä) | he menevät |
| mun raportti | minun raporttini, raporttini |
| kattoa, tsekata | katsoa, tarkistaa |
| kans | kanssa |

Markkinointiteksti, podcastin kuvaus tai some-julkaisu voi olla tarkoituksella puhekielinen. Säilytä tietoinen tyylivalinta, ja korjaa vain se, mikä on rekisteriin nähden vahingossa syntynyt.

## 6. Kirjoitusasun tarkistaminen

Älä arvaa vierassanan asua englannin perusteella, varsinkaan kaksoiskonsonantteja. Järjestys epävarmassa tapauksessa:

1. Kielitoimiston sanakirja: kirjoitusasu, taivutus ja rektio
2. Kielitoimiston ohjepankki: ohje ja perustelu
3. Iso suomen kielioppi: kuvaus rakenteesta

Jos sanakirja ei tunne sanaa, valitse mieluummin sana, jonka se tuntee.
